### Instrucció per a informes no descarregables

Quan un informe no es pugui descarregar com a PDF directe:
1. **Primer intent**: descarregar via URL directa
2. **Segon intent**: convertir la web a PDF amb Playwright (`web-to-pdf.js`)
3. **Tercer intent (NO OFICIAL)**: copiar el text de la web i crear un PDF no oficial amb el contingut complet. Marcar el fitxer com a `NO-OFICIAL` al nom.
