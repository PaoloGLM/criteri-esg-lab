## Sistema visual

- **Paleta**: #2C1810, #5C3A1E, #B87333, #E8C99A, #F5EFE6 (+ #D9A574 per darks)
- **Tipografia**: Fraunces (display + èmfasi italic), Inter (body), JetBrains Mono (meta + uppercase letter-spacing)
- **Layout**: border-top 3px + header amb eyebrow/title/big-number + body + footer amb llegenda + cita italic + URL
- **Numeració**: visible en tots els items (01, 02, 03...)
- **Badge Premium**: fons coure sòlid + text blanc

## Recomanacions d'ús

1. **Pel feed**: usa sempre verticals (1080×1350) o quadrats (1080×1080). LinkedIn els retalla menys.
2. **Per a articles**: usa les versions landscape (1200×630) com a cover.
3. **Per a llançaments grans**: usa el carousel PDF. És el format amb més engagement a LinkedIn.
4. **No redimensionis**: les imatges ja estan a 2x (2160×2160 real per a les quadrades) per màxima nitidesa en pantalles retina.
5. **Anomena sempre la font**: cada peça té la URL `criteriesg.com` al peu. No l'esborris.
