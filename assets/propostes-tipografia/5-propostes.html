Cada proposta mostra com es veuria la web amb diferents combinacions de fonts. Totes són de lliure accés (Google Fonts).

PROPOSTA 01

Newsreader + DM Sans + JetBrains Mono

Editorial i càlida, amb un toc literari que evoca premsa escrita de qualitat.

Bases: Newsreader (Production Type, 2020) — dissenyada per llegir notícies en pantalla. DM Sans (Colophon Foundry, 2019) — moderna, geomètrica, utilitària. JetBrains Mono per dades.
Per què: Newsreader té itàliques molt expressives (com Fraunces) però és més seriosa i menys decorativa. DM Sans és més neta que Inter. Conjunt editorial modern.

PROPOSTA 02

Source Serif 4 + Manrope + IBM Plex Mono

Institucional i professional, amb serietat acadèmica i claredat escandinava.

Bases: Source Serif 4 (Frank Grießhammer, Adobe, 2014-2022) — sòlida, llegible, institucional. Manrope (Mikhail Sharanda, 2018) — geomètrica, oberta, moderna. IBM Plex Mono (Mike Abbink, 2017) — tècnica, precisa.
Per què: Source Serif 4 transmet serietat sense ser avorrida. Manrope és més fresca que Inter, amb caràcter propi. El conjunt té un toc "think tank" / consultoria premium.

PROPOSTA 03

Crimson Pro + Outfit + Space Mono

Creativa i fresca, amb personalitat literària i un toc dissenyístic contemporani.

Bases: Crimson Pro (Jacques Le Bailly, 2015) — clàssica renaixentista modernitzada, elegant. Outfit (Rodrigo Fuenzalida, 2021) — geomètrica, juganera, amb caràcter. Space Mono (Florian Karsten, 2016) — retro-futurista, amb personalitat.
Per què: Crimson Pro té la calidesa d'una revista literària. Outfit és fresca i creativa sense perdre professionalitat. Space Mono dona un toc dissenyístic únic. Conjunt amb molta personalitat.

PROPOSTA 04

Bricolage Grotesque + Instrument Serif + JetBrains Mono

Trendy i editorial, amb contrast fort entre grotesque moderna i serif ornamentada.

Bases: Bricolage Grotesque (Mathieu Triay, 2023) — dissenyada per a revistes digitals, molt expressiva. Instrument Serif (Rodrigo Saiani, 2022) — serif de contrast alt, molt editorial. JetBrains Mono per dades.
Per què: Bricolage és la font del moment en disseny editorial digital (The New York Magazine, revistes independents). Instrument Serif té itàliques precioses. Conjunt amb moltíssima personalitat, fresc i creatiu.

PROPOSTA 05

Lora + Figtree + Fira Code

Càlida i accessible, amb un toc artesanal i Mediterrani que encaixa amb Criteri ESG.

Bases: Lora (Olga Karpushina, 2011) — serif amb influència cal·ligràfica, càlida, humana. Figtree (Nico Inosanto, 2022) — sans moderna, amable, molt llegible. Fira Code (Nikita Prokopov, 2015) — mono amb lligadures, tècnica.
Per què: Lora té una calidesa mediterrària que encaixa amb l'identitat de Criteri. Figtree és moderna però no freda. Fira Code dona un toc tècnic precís. Conjunt humà, proper i professional alhora.
