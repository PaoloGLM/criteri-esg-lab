## 1. RESUM EXECUTIU

**Què és B Corp**
Certificació global administrada per **B Lab** (entitat sense ànim de lucre) que avala empreses que compleixen alts estàndards de rendiment social i mediambiental, transparència i responsabilitat legal. No és un estàndard de reporting voluntari (com GRI), sinó una **certificació de tot l'ecosistema empresarial** amb requisits legals vinculants.

**Abast**
- **Universal**: Qualsevol mida, sector, geografia (excepte sectors exclosos per Risk Profile: tabac, armes, combustibles fòssils, joc, etc.).
- **Empresa sencera**: No certifica productes/serveis individuals, sinó l'entitat legal completa (inclou filials majors).
- **Recurrència**: Recertificació obligatòria cada **3 anys**.

**A qui obliga / Aplicabilitat**
- **Voluntària** per a empreses privades que sol·liciten la certificació.
- **Obligatòria** per a:
  - Empreses que volen usar la marca "Certified B Corporation".
  - Filials de grups on la mare ja és B Corp (s'han de certificar independentment si facturen >$5M o tenen >50 treballadors; altrament s'agrupen).
  - **Benefit Corporations** (forma legal EUA/altres jurisdiccions) *no* requereixen certificació B Corp, però n'és el camí habitual.

**Pilars BIA v6 (5 Àrees d'Impacte + Governança base)**
1. **Governança** (Governance) — Missió, ètica, transparència, estructura legal.
2. **Treballadors** (Workers) — Salaris, beneficis, formació, seguretat, participació.
3. **Comunitat** (Community) — Diversitat, equitat, inclusiò (DEI), proveïdors locals, donacions, voluntariat.
4. **Medi Ambient** (Environment) — Gestió ambiental, clima, aigua, residus, economia circular.
5. **Clients** (Customers) — Qualitat, seguretat, privacitat, impacte positiu productes/serveis.

**Requisits mínims durs (Hard floors)**
- **Puntuació BIA ≥ 80 punts** (sobre 200).
- **Requisit Legal**: Modificar estatuts/bylaws per incloure *stakeholder governance* (deure fiduciari ampliat a no accionistes) — **abans de certificar** (plazos jurídiccionals variables).
- **Disclosure Questionnaire** completat i sense "flags" no remediats (Minimum Safeguards).
- **Risk Profile** superat (sectors/pràctiques excloses).
- **Verificació** per B Lab Analyst (documentació + entrevista).

## 2. ESTRUCTURA

### 2a. Components Clau del Sistema B Corp

| Component | Descripció | Estat v6 / v2.2 |
| :--- | :--- | :--- |
| **BIA (B Impact Assessment)** | Eina d'autoavaluació online (200 punts max). Versió actual: **BIA v6** (llançament 2024). Estructura: 5 àrees, ~50 temes, ~200 preguntes. | **Vigent** (v6) |
| **B Lab Standards v2.2** | Nou marc de requisits (publicat **2026-02-20**). Substitueix la lògica "80 punts + legal" per **7 Impact Topics** amb *performance requirements* específics per mida/sector. | **Publicat 2026-02-20** (transició en curs) |
| **Disclosure Questionnaire** | Cuestionari de pràctiques sensibles (multes, sancions, controvèrsies). Part del procés de verificació. | **Obligatori** |
| **Minimum Safeguards** | Llindars mínims per tema (ex: salaris dignes, no treball infantil, emissions GHG mesurades). Si no es compleixen → no certifica. | **Integrats a Standards v2.2** |
| **Risk Profile** | Classificació de risc per sector/geografia. Determina profunditat de verificació i exclusions sectorials. | **Obligatori** |
| **Requisit Legal (Stakeholder Governance)** | Modificació estatuts per considerar impacte en *stakeholders* (treballadors, comunitat, medi ambient, clients). | **Obligatori pre-certificació** |
| **Verificació / Analyst Review** | Revisió documental + entrevista per Analista B Lab. Mostres aleatòries d'evidències. | **Obligatori** |
| **Recertificació** | Cada **3 anys** (nova BIA, nova verificació, actualització legal si cal). | **Obligatori** |
| **Quota Anual** | Basada en facturació (ex: <$1M → $2.000/an; $100M → ~$25k/an). | **Obligatori** |

## 3. INTEROPERABILITAT

| Estàndard / Marc | Relació amb B Corp (BIA v6 / Standards v2.2) | Notes d'alineació |
| :--- | :--- | :--- |
| **GRI (Universal Standards 2021)** | BIA v6 pregunta dades alineades amb GRI (ex: GRI 2-7, 2-30, 302, 305, 401, 403, 404, 405, 413, 416). **No substitueix** informe GRI. | B Lab publica *crosswalk* BIA-GRI **[pendent de verificar al PDF B Corp]**. |
| **CSRD / ESRS** | Empreses subjectes a CSRD han de reportar ESRS. BIA v6 cobreix molts *datapoints* ESRS (E1 clima, S1 treballadors, S3 comunitats, G1 governança). **No garanteix** compliment CSRD complet. | Standards v2.2 (2026) pretenén major alineació ESRS **[pendent de verificar al PDF B Corp]**. |
| **SASB (IFRS Foundation)** | BIA inclou temes materials per sector (com SASB). Preguntes BIA sobre GHG, aigua, seguretat laboral, privacitat → alineades SASB. | Útil per omplir SASB *industry standards*. |
| **MSCI ESG Ratings** | MSCI valora certificació B Corp com a *signal* positiu (governança, transparència). No hi ha mapeig automàtic de puntuació. | Complementari. |
| **ISSB / IFRS S1 & S2** | IFRS S2 (clima) → BIA Env (GHG, riscos climàtics, objectius). IFRS S1 (general) → Gov + Disclosure. | B Lab participa en consultes ISSB. |
| **TCFD** | BIA v6 Env: Governança climàtica, estratègia, gestió riscos, mètriques/objectius (GHG Scope 1,2,3). **Alineació alta**. | Recomanat per B Lab per a gran empresa. |
| **CDP** | Preguntes BIA Env (GHG, aigua, boscos) → compatibles amb qüestionaris CDP. Empreses B Corp solen respondre CDP. | Sinergia documental. |
| **TNFD** | BIA v6 Env: Biodiversitat, ús sòl, aigua. Standards v2.2 (Topic: Nature) → alineació TNFD (LEAP). | **En desenvolupament** a Standards v2.2 **[pendent de verificar al PDF B Corp]**. |
| **ISO 26000** | BIA v6 estructura inspirada en ISO 26000 (7 temes central: Gov, DH, Pràctiques laborals, Medi ambient, Pràctiques justes, Consumidors, Comunitat). | Base conceptual compartida. |

## 5. PUNTS D'IMPACTE TÍPICS (Gaps Comuns Detectats en Auditories Prèvies)

> Basat en patrons observats en processos BIA v6; **no són dades del PDF** sinó experiència operativa. Validar cada cas.

| Àrea | Punt Crític Frequent | Conseqüència si no es resol |
| :--- | :--- | :--- |
| **Governança** | **Requisit Legal no completat** (estatuts no modificats / jurisdicció sense forma *Benefit Corp* clara). | **Bloqueig certificació** (hard stop). |
| **Governança** | Missió social/ambiental no inclosa en estatuts o sense mètrica de seguiment. | Puntuació baixa Gov; risc Disclosure. |
| **Treballadors** | **Living Wage** no verificat per a tots els treballadors (incl. subcontractats in-situ). | Minimum Safeguard no superat (v2.2) / punts perduts v6. |
| **Treballadors** | Falta sistematització formació / plans carrera / enquestes clima laborals. | Punts Wrk baixos; dificultat >80. |
| **Comunitat** | **DEI**: Dades desglossades (gènere, ètnia, discapacitat) per nivell jeràrquic no existents. | Punts Com baixos; risc reputacional. |
| **Comunitat** | Cadena subministrament: sense codi conducte signat / sense auditories RSC proveïdors clau. | Punts Com; Minimum Safeguard v2.2 (Human Rights). |
| **Medi Ambient** | **GHG Scope 3** no calculat (o només categories 1-2). Objectius **no SBTi**. | Punts Env crítics; v2.2 Topic "Climate Action" requereix SBTi o equivalent. |
| **Medi Ambient** | Sense sistema gestió ambiental (ISO 14001 o equivalent documentat). | Punts Env; v2.2 Topic "Environmental Management". |
| **Clients** | Productes sense avaluació impacte salut/seguretat / accessibilitat / privacitat per disseny. | Punts Cus; v2.2 Topic "Consumer Welfare". |
| **Disclosure** | Controvèrsia no declarada / multa ambiental / laboral pendent. | **Denegació certificació** (Minimum Safeguard). |
| **Risk Profile** | Sector "High Risk" (ex: confecció, alimentació, mineria) → verificació *enhanced* (site visit, més documents). | Retards 3-6 mesos; cost addicional. |
