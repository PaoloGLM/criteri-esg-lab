## 2. MAPA TEMÀTIC I REQUISITS CONCRETS

### 2a. Estructura dels 4 Pilars i 11 Recomanacions

| Pillar | Recomanació (Codi) | Descripció sintètica |
|--------|-------------------|----------------------|
| **Governança** | **G-a** | Descriure la supervisió del consell sobre riscos i oportunitats climàtiques. |
| | **G-b** | Descriure el paper de la direcció en l'avaluació i gestió de riscos/oportunitats climàtiques. |

| | **S-c** | Descriure la resilient de l'estratègia tenint en compte diferents escenaris climàtics (incloent 2°C o menys). |

| | **RM-b** | Descriure els processos de gestió de riscos climàtics. |
| | **RM-c** | Descriure com s'integren els processos climàtics en la gestió de riscos global de l'organització. |

| | **M-b** | Divulgar emissions GEH Scopes 1, 2 i 3 i els riscos relacionats. |
| | **M-c** | Descriure els objectius climàtics i el rendiment enfront d'aquests. |

## 3. INTEROPERABILITAT AMB ALtres MARCS

| Marc / Regulació | Relació amb TCFD | Nivell Alineació | Punts Clau Convergència / Divergència |
|------------------|------------------|------------------|----------------------------------------|
| **CSRD / ESRS E1 (UE)** | **Base estructural**. ESRS E1 replica els 4 pilars TCFD. | **Molt Alta** (≈95%) | • ESRS E1 **obligatori** (vs. voluntari TCFD original)<br>• ESRS requereix **doble materialitat** (impacte + financera); TCFD = materialitat financera<br>• ESRS E1: més granulat (DR E1-1 a E1-9), datapoints quantitatius obligatoris<br>• Escenaris: ESRS exigeix **mínim 2** (incl. ≤1.5°C / NZ2050) + anàlisi sensibilitat<br>• Scope 3 obligatori si material (TCFD: recomanat)<br>• Taxonomia UE integrada (CapEx/OpEx/Ingressos verds) |
| **ISSB / IFRS S2 (Global Baseline)** | **Successor directe**. IFRS S2 = TCFD + millores. | **Molt Alta** (≈98%) | • ISSB va assumir monitoratge TCFD (oct-2023)<br>• IFRS S2 manté 4 pilars + 11 recomanacions<br>• Afegits: **resiliència** (quantitativa), **Scope 3 obligatori**, **objectius base ciència**, **governança competències**, **integració reporting financer**<br>• Jurisdiccions adopten IFRS S2 com a base (UK, AU, CA, SG, JP, BR, etc.) |
| **SFDR (UE) — Article 8/9** | Alineació parcial via *Principal Adverse Impacts* (PAI). | **Mitjana** | • PAI indicadors climàtics (1-6) mapen a Mètriques TCFD (GEH, intensitat, fòssils)<br>• SFDR no requereix escenaris ni estratègia resilient<br>• Taxonomia UE (Article 8) → CapEx verd TCFD |
| **Taxonomia UE (Reg. 2020/852)** | Mètriques TCFD (CapEx verd, OpEx verd, Ingressos verds) alineades amb KPIs Taxonomia. | **Alta (Mètriques)** | • Taxonomia defineix "verd" tècnicament (TSC, DNSH, MSS)<br>• TCFD M-a: CapEx verd = % CapEx

### 3.5 Interoperabilitat TCFD ↔ ISSB (IFRS S1/S2) ↔ ESRS (CSRD) — *Completada*

> **Nota clau**: Amb la dissolució del TCFD (oct-2023) i la traspàs de competències a l'**ISSB**, l'alineació *de facto* és amb **IFRS S2**. La **CSRD/ESRS** (UE) adopta "double materiality" però alinea definicions climàtiques (Gov, Strat, Risk, Metrics) amb ISSB per evitar fragmentació (*Interoperability Guidance ISSB-EFRAG, mai-2024*).

| Dimensió | TCFD (Legacy) | **IFRS S2 (ISSB)** | **ESRS E1 (CSRD)** | Gap / Acció Requerida |
| :--- | :--- | :--- | :--- | :--- |
| **Governança** | Supervisió Consell / Paper Direcció | **S2 §6(a-b)**: Governança + Competències + Remuneració | **GOV-1, GOV-3, GOV-4**: Estructura, Integració sostenibilitat, Remuneració | **Baix**: ESRS més granulat en *due diligence* i *stakeholder engagement*. |
| **Estratègia** | Riscos/Oportunitats + Escenaris | **S2 §9-13**: Model negoci, Escenaris (obligatori ≥2, incl. 1.5°C), Resiliència | **E1-1, E1-4, E1-5**: Transició, Escenaris, Resiliència, *Locked-in* emissions | **Mitjà**: ESRS exigeix *Transition Plan* explícit (E1-1) i *Locked-in* (E1-5). TCFD/ISSB implícit. |
| **Gestió Riscos** | Procés Identificació/Avaluació | **S2 §25-26**: Procés integrat gestió riscos, Inputs escenaris | **E1-2, GOV-2**: Polítiques, Accions, Recursos, *Due diligence* | **Mitjà**: ESRS vincula a *due diligence* cadena valor (ESRS 2 MDR-P). |
| **Mètriques** | GHG S1/S2/S3, Targets, Remun. | **S2 §29-37**: GHG (GHG Protocol), Targets (base year, %S3), Intensitat, Preu Carboni, Assurance | **E1-6 a E1-9**: GHG gross/net, Remocions, Credits, Targets, Energies, *Taxonomy* KPIs | **Alt**: ESRS separa *Gross* vs *Net* (remocions/crèdits), exigeix % Taxonomia Verd, *Energy Mix*. ISSB més flexible en S3 (estimació). |
| **Materialitat** | *Single Materiality* (Impacte financer) | **S1 §17-19**: *Sustainability-related risks & opportunities* (Financial Materiality) | **ESRS 1 §3.4**: **Double Materiality** (Impact + Financial) | **Crític**: Per UE, cal avaluar *Impact Materiality* (inside-out) addicional. Fora UE, ISSB = *Financial* nadiu. |
| **Cadena Valor (S3)** | Recomanat si rellevant | **S2 §29(a)(iii)**: *If available without undue cost/effort* (Estimació acceptada) | **E1-6**: Obligatori *upstream/downstream* (estimació acceptada però amb metodologia robusta) | **Alt**: ESRS més estricte en granularitat S3 (categories GHG Protocol) i freqüència actualització. |

**Checklist Interoperabilitat Pràctica (Ready-for-ISSB/CSRD):**
- [ ] **Unificació Base Year**: Únic any base per GHG, Targets i Escenaris (TCFD/ISSB/ESRS).
- [ ] **Metodologia Escenaris**: Documentar paràmetres (IEA NZE2050, NGFS Current Policies, etc.) i horizons (2025, 2030, 2050) comuns.
- [ ] **Data Pipeline S3**: Automatitzar recol·lida dades proveïdors (CDP Supply Chain, EcoVadis, API sectorials) per satisfer *undue cost/effort* (ISSB) i *robust estimation* (ESRS).
- [ ] **Assurance Ready**: Preparar *evidence package* per ISAE 3410 (ISSB) i *limited assurance* ESRS (any 1) → *reasonable* (any 3+).
- [ ] **Taxonomia UE**: Mapeig CAPEX/OPEX/Turnover a activitats elegibles/alinades (ESRS E1-9 / Art. 8 Tax Reg) — *No requerit per ISSB*.
